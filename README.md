# RUL Vision – Predictive Maintenance

## About the Project
RUL Vision is a machine learning-based predictive maintenance project that predicts the Remaining Useful Life (RUL) of aircraft engines using sensor data from the NASA C-MAPSS dataset.

## Features
- Remaining Useful Life prediction
- Bi-LSTM deep learning model
- XGBoost model comparison
- Model evaluation using MAE, RMSE, and R²
- Engine health assessment and priority scoring
- Maintenance recommendations
- Interactive dashboard using Gradio

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- TensorFlow/Keras
- XGBoost
- Matplotlib
- Gradio

## Dataset
NASA C-MAPSS turbofan engine degradation dataset (FD001).

## Project Status
Working academic prototype. Further validation and improvements are needed before real-world deployment.
